# ChurnTrackAI

Sistema de Analítica Predictiva para la Predicción de Churn en Empresas B2B mediante Redes Neuronales.

Esta versión usa un **Static Space** gratuito de Hugging Face. La inferencia del modelo se ejecuta en el navegador mediante JavaScript usando los pesos exportados desde la red neuronal entrenada en Google Colab.

Archivos:
- `index.html`
- `modelo.js`

No se requiere Python, TensorFlow ni Gradio en el Space.
